# VALORA Pro - Logo Assets

Coloca aqui tus archivos de logo:

- valora-icon-light.svg     (logo para fondos oscuros)
- valora-icon-dark.svg      (logo para fondos claros)
- valora-horizontal-light.svg
- valora-horizontal-dark.svg

Luego actualiza BRAND en src/main.js:

  logo: {
    light: { icon: '/src/assets/logo/valora-icon-light.svg' },
    dark:  { icon: '/src/assets/logo/valora-icon-dark.svg'  }
  }
